# ನನ್ನ ಕನ್ನಡ

**ನನ್ನ ಕನ್ನಡ. ನನ್ನ ಕರ್ನಾಟಕ. ನನ್ನ ಸ್ವಾಭಿಮಾನ.**

ಕನ್ನಡ ಕಲಿಕೆ, ಪ್ರಾದೇಶಿಕ ಮಾತಿನ ಅನ್ವೇಷಣೆ, ಹೊಸಬರ ದಿನನಿತ್ಯದ ಸಂಭಾಷಣೆ ಮತ್ತು ಮೂಲಸಹಿತ ಕರ್ನಾಟಕ ಪರಂಪರೆಯನ್ನು ಒಂದೇ ಕನ್ನಡ-ಮೊದಲ ವೇದಿಕೆಯಲ್ಲಿ ಜೋಡಿಸುವ ಸಾರ್ವಜನಿಕ ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್.

- ಸಾರ್ವಜನಿಕ ತಾಣ: https://nanna-kannada.cometocean257.chatgpt.site
- ಮೂಲಸಂಕೇತ: https://github.com/Darshan-paapani06/nanna-kannada

## ಈಗ ಕೆಲಸ ಮಾಡುವ ಅನುಭವಗಳು

- ಪೂರ್ಣ-ವೀಕ್ಷಣೆಯ `ನನ್ನ ಕನ್ನಡ → ನನ್ನ ಕರ್ನಾಟಕ → zoom-out` ಪ್ರವೇಶ; ಸ್ಕಿಪ್, replay ಮತ್ತು reduced-motion.
- ಸಂದರ್ಭಾಧಾರಿತ ಪಾಠ, ಸಾಧನದ speech synthesis, ಪ್ರಗತಿ ಮತ್ತು ಕ್ವಿಜ್.
- ದಕ್ಷಿಣ, ಉತ್ತರ, ಕಲ್ಯಾಣ ಕರ್ನಾಟಕ ಮತ್ತು ಕರಾವಳಿ ಕನ್ನಡದ ಜವಾಬ್ದಾರಿಯುತ ಪ್ರಾದೇಶಿಕ ಪರಿಚಯ/ಹೋಲಿಕೆ.
- ಮೂಲಸಹಿತ ಐತಿಹಾಸಿಕ ಕಾಲರೇಖೆ ಮತ್ತು ಪರಂಪರೆ ಸಂಗ್ರಹ.
- ಕೀಲಿಯಿಲ್ಲದ, ಡೇಟಾಬೇಸ್-ಆಧಾರಿತ ಸೀಮಿತ ಕನ್ನಡ ಮಿತ್ರ.
- ಮೈಕ್ ಅನುಮತಿಯೊಂದಿಗೆ ಸಾಧನದಲ್ಲೇ ಧ್ವನಿ ದಾಖಲಿಕೆ/ಮರುಶ್ರವಣ.
- ಪರಿಶೀಲನೆ-ಬಾಕಿ ಸಮುದಾಯ ಕೊಡುಗೆ ಮತ್ತು D1 persistence schema.
- ಐದು ಹಂತದ ಪಯಣ ಮತ್ತು ಮುದ್ರಿಸಬಹುದಾದ ವೈಯಕ್ತಿಕ ಪ್ರಮಾಣಪತ್ರ.
