# Repository instructions

- Keep visitor-facing chrome Kannada-first; optional English belongs only inside learning assistance.
- Preserve the red/yellow/black brand and the accessible cinematic intro state machine.
- Do not publish regional expressions or historical claims without a source and review state.
- Never classify Tulu, Kodava, Konkani, or Malayalam as Kannada dialects.
- Keep credentials server-side; validate all writes, require identity, rate-limit, and store contributions as `pending`.
- Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` before release.
- Do not claim GitHub or deployment success until the exact public URL has been checked unauthenticated.
