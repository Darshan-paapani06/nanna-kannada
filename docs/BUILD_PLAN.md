# ನನ್ನ ಕನ್ನಡ — ನಿರ್ಮಾಣ ಯೋಜನೆ

## ಗುರಿ

ಕನ್ನಡ ಕಲಿಕೆ, ಪ್ರಾದೇಶಿಕ ಮಾತು, ಕರ್ನಾಟಕದ ಇತಿಹಾಸ ಮತ್ತು ಹೊಸಬರ ದಿನನಿತ್ಯದ ಸಂಭಾಷಣೆಯನ್ನು ಒಂದೇ ಕನ್ನಡ-ಮೊದಲ ಸಾರ್ವಜನಿಕ ಅನುಭವದಲ್ಲಿ ಜೋಡಿಸುವುದು.

## ಹಂತಗಳು

1. **ದೃಶ್ಯ ಅಡಿಪಾಯ** — ಕನ್ನಡ ಅಕ್ಷರಶೈಲಿ, ಕೆಂಪು–ಹಳದಿ ವಿನ್ಯಾಸ, ಪ್ರವೇಶಾನುಕೂಲತೆ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯಾಶೀಲ ಚೌಕಟ್ಟು.
2. **ಸಿನಿಮಾಟಿಕ್ ಪ್ರವೇಶ** — `takeover → nannaKannada → nannaKarnataka → zoomOut → complete` ಸ್ಥಿತಿ ಯಂತ್ರ, ಸ್ಕಿಪ್, ಕಡಿಮೆ ಚಲನೆ ಮತ್ತು ಮರುಪ್ರದರ್ಶನ.
3. **ಮೂಲ ಸಮಸ್ಯೆ** — ಪ್ರದೇಶ ಹುಡುಕಾಟ, ಮೂಲಸಹಿತ ನುಡಿಗಟ್ಟುಗಳು, ಹೋಲಿಕೆ, ಮತ್ತು ಜಿಲ್ಲೆ/ಪ್ರದೇಶ ವಿವರ.
4. **ಕಲಿಕೆ ಮತ್ತು ಬದುಕು** — ಪಾಠಗಳು, ಸಂಭಾಷಣಾ ಅಭ್ಯಾಸ, ಕ್ವಿಜ್, ಪ್ರಗತಿ ಮತ್ತು ಪ್ರಮಾಣಪತ್ರ.
5. **ಇತಿಹಾಸ ಮತ್ತು ಪರಂಪರೆ** — ಮೂಲಸಹಿತ ಕಾಲರೇಖೆ, ಪರಂಪರೆ ಸ್ಥಳಗಳು ಮತ್ತು ವಾಸ್ತವ/ಜನಪದ ವ್ಯತ್ಯಾಸ.
6. **ಬುದ್ಧಿವಂತ ಸಹಾಯ** — ಕೀಲಿಯಿಲ್ಲದ ಮೂಲಾಧಾರಿತ ಕನ್ನಡ ಮಿತ್ರ; ಮೈಕ್ ಅನುಮತಿ ಮತ್ತು ಸ್ಥಳೀಯ ಧ್ವನಿ ಮರುಶ್ರವಣ.
7. **ಸಮುದಾಯ ಮತ್ತು ಸಂಗ್ರಹಣೆ** — ಪರಿಶೀಲನೆಗೆ ಮಾತ್ರ ಹೋಗುವ ಕೊಡುಗೆಗಳು, ವರದಿ, ಗುರುತಿನ ಆಧಾರಿತ ಉಳಿವು ಮತ್ತು D1 ಸಂಗ್ರಹಣೆ.
8. **ಬಿಡುಗಡೆ** — ಸ್ವಯಂಚಾಲಿತ ಪರೀಕ್ಷೆ, ಭದ್ರತಾ ಪರಿಶೀಲನೆ, ಸಾರ್ವಜನಿಕ ಮೂಲಸಂಗ್ರಹ ಮತ್ತು HTTPS ನಿಯೋಜನೆ.

## ಗುಣಮಟ್ಟದ ಗೇಟ್‌ಗಳು

- ಬಿಳಿ ಫ್ಲ್ಯಾಶ್ ಇಲ್ಲದ ಪೂರ್ಣ-ವೀಕ್ಷಣಾ ಪ್ರವೇಶ; ಕೀಬೋರ್ಡ್ ಸ್ಕಿಪ್ ಮತ್ತು reduced-motion ಬೆಂಬಲ.
- ಸಾರ್ವಜನಿಕ UI ಕನ್ನಡದಲ್ಲೇ; ಕಲಿಕಾ ನೆರವಿನಲ್ಲಿ ಮಾತ್ರ ಐಚ್ಛಿಕ ಅನುವಾದ.
- ಪ್ರಾದೇಶಿಕ/ಐತಿಹಾಸಿಕ ದಾಖಲೆಗಳಿಗೆ ಮೂಲ ಅಥವಾ ಸ್ಪಷ್ಟ ಪರಿಶೀಲನೆ-ಬಾಕಿ ಗುರುತು.
- AI, ಉಚ್ಚಾರಣೆ ಮತ್ತು ಸಮುದಾಯ ವಿಷಯದ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಅತಿಶಯಿಸದ ಪಾರದರ್ಶಕ ಸ್ಥಿತಿಗಳು.
- `lint`, TypeScript, ಪರೀಕ್ಷೆ ಮತ್ತು ಉತ್ಪಾದನಾ build ಯಶಸ್ಸು.
